# Анализ портфеля акций

## Обзор

Этот проект посвящён анализу активно управляемого портфеля акций.

Цели анализа:

- оценка доходности портфеля;
- оценка характеристик риска;
- анализ диверсификации;
- определение источников доходности;
- оценка доходности с учётом риска;
- проверка устойчивости портфеля в различных рыночных режимах.
